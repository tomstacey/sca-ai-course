# AI in Supply Chain: practice files

Supply Chain Academy · Tuesday 10 November 2026

**Everything here is fictional.** Contoso Freight Ltd, its people, customers, hauliers and figures are invented for training, so these files are safe to upload to Copilot Chat on your work account.

## Get the files

- **All at once:** click the green **Code** button above, choose **Download ZIP**, then unzip it.
- **One file:** click the file's name, then the download button at the top right of the file view.

## What's inside

| File | What it's for |
|---|---|
| `00_Read_me.txt` | This list, for when the files arrive by email or USB stick |
| `01_Prompts_to_copy.txt` | Every prompt used in the activities, ready to copy and paste |
| `02_Company_profile.docx` | Who Contoso Freight is: sites, people, customers and targets |
| `03_Incident_report.docx` | Prompt Grand Prix, card A: summarise |

| `05_Haulier_email_thread.docx` | Prompt Grand Prix, card C: respond to a haulier |
| `06_Research_brief.docx` | Prompt Grand Prix, card D: research with sources you can check |
| `07_Delivery_exceptions.xlsx` | Prompt Grand Prix, card E: analyse, and the afternoon session |
| `08_Supplier_risk_briefing.docx` | Spot the hallucination |

## How to use them

1. Open Copilot Chat with your work account.
2. Start a new chat for each task.
3. Attach the file, then paste or type your prompt.
4. Check what comes back against the file. You own what you send.
